# 0034 — Активная версия промпта — это старший файл, а не константа

## Контекст

ADR 0004 сделал промпт версионированным файлом, но оставил номер версии в коде:
`PROMPT_VERSION = 7` в `app/worker/answerer.py`. Файл и число кода стали двумя источниками правды
об одном факте — какая версия работает. Расхождение стоит дорого и молчит: положили `v8.md`,
прогнали оценку, записали измерение, а сервис продолжает рендерить `v7`, и аудит честно пишет
`prompt_version: 7`, поэтому по журналу всё сходится.

Тот же номер дублировался в четырёх строках аудита (`answer_completed`, `answer_rejected`,
`answer_unavailable`) плюс в запросе `CompletionRequest`. Правка одной из них оставляла трейс
внутренне непротиворечивым и неверным.

Индекс документации уже считает старший файл текущим: `docs/README.md` помечает `v7` как
«текущая». Каталог и так был списком версий, просто код его не читал.

## Решение

`PromptLibrary.versions(name)` читает каталог и возвращает версии по возрастанию;
`load_latest(name)` грузит старшую. `Answerer` не знает номера вовсе: он грузит `load_latest` и
пишет в аудит `prompt.version` из загруженного файла. Строк `PROMPT_VERSION` в коде ответа нет.

- Новая версия — новый файл-пара `vN.md` + `vN.meta.yaml`. Публикация файла и есть активация,
  потому что `vN.meta.yaml` обязан назвать измерение в `docs/measurements/`.
- Откат — удалить (или переименовать) файл-пару старшей версии. Это один дифф, видимый на ревью,
  и он же возвращает индекс документации в прежнее состояние.
- Пустой каталог, каталог без `v<number>.md` и запрос несуществующей версии — `PromptNotFoundError`,
  то есть отказ на старте, а не пустой промпт.

## Последствия

- `apps/api/tests/test_prompt_library.py` проверяет каталог, а не константу: сортировку версий
  (`2, 10` — по числу, не по строке), загрузку старшей, отказ на пустом каталоге, и что реальный
  `docs/prompts` грузит именно старшую версию.
- `apps/api/tests/test_answerer.py` проверяет, что в аудит попадает `prompt.version` из файла.
- Константы `PROMPT_VERSION` у `contextual` и `sentiment` остаются: там номер — умолчание настройки
  (`CONTEXTUAL_PROMPT_VERSION`), то есть конфигурация, а не второй источник правды о файле.
- Ветка «промпт, который правит HR в базе», отклонённая в ADR 0004, остаётся отклонённой по тем же
  причинам; это решение меняет только способ выбрать активную версию.

# Согласование скидок

Материал для подразделения продаж.

## Уровни решений

Скидку до 5% от прайса менеджер предоставляет самостоятельно. Скидка от 5% до 10% согласуется с
руководителем группы. Скидка выше 10% — только с директором по продажам, письменно.

## Что приложить к запросу

К запросу на скидку прикладывают расчёт маржинальности и объём заказа. Запрос без расчёта не
рассматривается.

## Срок ответа

Стандартный срок согласования — один рабочий день. Запрос по тендеру рассматривается до трёх
рабочих дней.

## Ограничения

Скидка не суммируется с акциями без отдельного согласования. Скидка ниже себестоимости запрещена:
такой запрос отклоняется без рассмотрения.

## Скидка при продлении

Продление действующего контракта не требует нового согласования, если скидка не выросла. Рост
скидки согласуется по общим уровням.

## Скидка на логистику

Стоимость доставки не входит в скидку от прайса и согласуется отдельно с логистикой. Суммарная
выгода клиента не должна превышать уровень, согласованный для скидки.

## Отчёт по скидкам

Директор по продажам получает отчёт по выданным скидкам ежемесячно, до 5-го числа. Аномалии
разбираются с руководителями групп.

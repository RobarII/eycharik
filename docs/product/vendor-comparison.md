# Сравнение вендоров для пилота в российском контуре

Этот файл — **единственный дом цен** в репозитории. Другой документ либо ссылается сюда, либо
цитирует число как `quoted from vendor-comparison`; цена, уплывшая в третье место, — так бизнес-кейс
проваливает проверку.

Цены сняты **2026-10-25**. У каждой строки есть источник, валюта, режим НДС и класс уверенности. Цена
без этих четырёх — слух, а слух в бизнес-кейсе превращается в проигранный спор на закупочной встрече.

## Классы уверенности

| Класс | Значение | Чего стоит |
|---|---|---|
| **A** | публичная цена из прайса на сайте вендора или в PDF тарифов | годна до следующей смены цены; просите срок действия |
| **B** | цена из приложения к договору (`ПРИЛОЖЕНИЕ №…` к договору) | годна для этого договора; новому клиенту могут назвать другие числа |
| **C** | публичной цены нет; нужно письменное предложение | не может войти в бизнес-кейс, пока предложения нет |

## Единственное сравнение, которое этот файл выдерживает

| Вариант | На ответ | Фиксированные ₽/месяц | Уверенность |
|---|---|---|---|
| Хостинговый API в РФ (`GigaChat3-10B` + `bge-m3` + `bge-reranker-v2-m3`) | 0.0306 | ≈ 0 | B |
| Одна L4 24 GB, self-hosted | пока не измерить | 71 456 | A |
| Одна L40S 48 GB, self-hosted | пока не измерить | 173 479 | A |

Арифметика окупаемости, с оговоркой выше: `71 456 ÷ 0.0306 ≈ 2.3 million answers/month` для L4,
`5.7 million` для L40S. Это проверка масштаба на здравый смысл, а не рекомендация.

## Чего этот файл сказать не может

- **Качество ответов.** Бенчмарки вендоров и MTEB — не наш золотой набор; решают только
  [оценки](../evals/README.md), по каждому профилю-кандидату, с файлом измерения.
- **Задержка.** Гейты — `p95_completion_ms ≤ 8000` и `p95_answer_ms ≤ 15000`; более дешёвая модель,
  которая их не проходит, не дешевле: она эскалирует.
- **Доступность.** Один вендор — один режим отказа; порты позволяют второго, матрица оценок — нет
  ([0010](../decisions/0010-one-model-vendor.md)).
- **Стабильность цены.** Ни один вендор из списка не публикует срок действия цены. Просите его
  письменно; фиксация цены на 90 дней стоит больше скидки в 3 %.

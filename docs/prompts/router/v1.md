# Задача

Определите тип входящего сообщения сотрудника.

# Категории

- `scenario` — ответ на текущий шаг онбординга (кнопка, «готово», файл, короткое подтверждение).
- `question` — вопрос о компании, процессах, документах, льготах.
- `escalate` — личный или чувствительный вопрос, который должен уйти человеку.
- `smalltalk` — приветствие, благодарность, оффтоп.

# Формат

```json
{"intent": "question", "confidence": 0.0}
```
